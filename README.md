# cs365-devops-capstone

CI/CD Pipeline with Terraform, EKS, GitHub Actions and Helm

- How to Run This Project
  cd EKS-Terraform-GitHub-Actions
  cd eks

- Install Required Tools
  Make sure you have: Terraform (version 1.9.x)
  Check version: terraform -v

- Initialize Terraform (Skip AWS backend)
  terraform init -backend=false
